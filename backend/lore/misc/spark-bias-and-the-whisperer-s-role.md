# Spark-Bias and the Whisperer's Role
Because magic is a biological byproduct of chaos, a crew's emotional state can destabilize the chaos-reaction inside Aetheric coils — this is **Spark-Bias**. A **Whisperer** (typically Flower-Folk, using empathic "social radar") harmonizes a crew's emotional output to prevent feedback loops from desyncing the ship's systems. No contradictions found here — consistent wherever it appears, and it doesn't depend on which cosmology model is true, so nothing needed updating.
